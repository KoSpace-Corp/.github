## Mission

Make everyday work faster, simpler and free.

KoSpace builds open-source products for the tools you use every day.
Every line of code is public. Every product is built to work with the others.

## Principles

- **Open by default.** Code, roadmap and decisions are public.
- **Built for daily use.** If it doesn't save time every day, it doesn't ship.
- **One ecosystem.** Our apps share design, data formats and conventions.
- **Fast iteration.** Ship, learn, improve.

## Get Involved
